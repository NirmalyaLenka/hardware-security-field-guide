# Getting Started

## If you own no hardware at all yet

Start by reading [Electronics Fundamentals](electronics/fundamentals.md) and [UART](protocols/uart.md). Both are readable without any equipment and will tell you exactly what to buy next.

## Minimum hardware to do hands-on work

- One ESP32 or Arduino-family dev board (~$5–10)
- One USB-to-UART adapter, if your board doesn't already have one built in (~$3–5)
- A basic DC multimeter (~$15)

This is enough for [Lab 01](practical-labs/lab-01-uart-console.md) and most of Levels 1–2.

A logic analyzer (~$10–25 for a Saleae-compatible clone) unlocks Level 3 ([Debugging](debugging/uart-console-discovery.md)). A SPI flash programmer (~$5–10) unlocks Level 4 ([Firmware](firmware/firmware-basics.md)).

## Your first hour

1. Read [Electronics Fundamentals](electronics/fundamentals.md).
2. Read [UART](protocols/uart.md).
3. Do [Lab 01](practical-labs/lab-01-uart-console.md) on a board you own.
4. Read [Safety and Authorized Use](safety/index.md) in full before going any further — it applies to every page after this point.

## If you get stuck

Check the "What can go wrong" section inside each guide first — it's written for the exact failure modes of that guide (a dedicated `troubleshooting/` section is planned but not yet populated; see the [Learning Path](learning-path.md) status notes). For anything broader, see the [FAQ](faq.md).
