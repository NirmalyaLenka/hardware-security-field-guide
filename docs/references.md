# References

This page collects the authoritative sources cited across the guide. Per-page references remain in each guide's own "References" section; this is a consolidated index.

## Standards and vendor documentation
- Texas Instruments, "Logic Guide" (SDYU001).
- Espressif Systems, ESP32 Series Datasheet.
- Arduino, official "Digital Pins" documentation.
- Silicon Labs, CP2102 USB-to-UART Bridge datasheet.
- Winbond, W25Q32 SPI NOR Flash datasheet.

## Tools
- [`sigrok` / PulseView](https://sigrok.org/) — open-source logic analyzer software.
- [`flashrom`](https://www.flashrom.org/) — open-source flash chip programming tool.
- [`binwalk`](https://github.com/ReFirmLabs/binwalk) — firmware image analysis tool.

## Frameworks referenced for structure (not reproduced)
- OWASP, IoT Security Testing Guide — general threat-modeling structure.
- NIST IR 8259, Foundational Cybersecurity Activities for IoT Device Manufacturers.

## Related community resources
- [swisskyrepo/HardwareAllTheThings](https://github.com/swisskyrepo/HardwareAllTheThings) — a broad, community-maintained hardware/IoT pentesting wiki that inspired this project's scope. This project is an independent work with original explanations, structure, and examples; no content was copied from it.
