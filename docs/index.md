# Hardware Security Field Guide

A practical, beginner-friendly guide to understanding, debugging, and securing hardware and IoT devices — from basic electronics and communication protocols to firmware analysis and responsible security testing.

## Who this is for

Students, electronics hobbyists, embedded engineers, IoT developers, and anyone starting out in hardware security who wants to *build up* understanding rather than copy-paste commands.

## What you can learn or build

By working through this guide you should be able to: identify and safely probe an unlabeled UART console, read communication protocols with a logic analyzer, extract and inspect a firmware image from a device you own, and reason about a device's attack surface using a simple threat model.
