# Security Policy

## Authorized use only

This project is educational. Every technique described here must only be applied to hardware you own, or hardware you have explicit, documented permission to examine. See [docs/safety/index.md](docs/safety/index.md) for the full policy.

## Reporting a vulnerability in this project's own code or documentation

If you find a factual security error in this guide (an incorrect wiring diagram, an unsafe procedure presented as safe, a script with a real flaw), please open a GitHub issue with:

1. The affected file and section.
2. What is incorrect or unsafe.
3. A reference supporting the correction, if available.

## Reporting a vulnerability in a third-party device you found using this guide

This project does not accept or publish zero-day vulnerability details about third-party products. If your use of this guide leads you to discover a real vulnerability in someone else's product:

1. Do not publish exploit details here or elsewhere before the vendor has had a reasonable opportunity to fix it.
2. Contact the vendor directly, or through a coordinated-disclosure platform if the vendor has no direct contact channel.
3. Once a fix is public, you are welcome to contribute a sanitized, educational write-up back to this project via the normal [contribution process](CONTRIBUTING.md).

## Supported versions

This is a documentation and educational-example project, not a software product with ongoing security patches. There is no formal version-support table.
