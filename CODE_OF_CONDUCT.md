# Code of Conduct

## Our standard

Participants in this project are expected to be respectful, constructive, and honest — particularly about what has and has not been tested, and about the authorization boundaries described in [docs/safety/index.md](docs/safety/index.md).

Unacceptable behavior includes harassment of any kind, personal attacks, sharing others' private information without consent, and submitting content that facilitates unauthorized access to systems the contributor does not own or have permission to test.

## Scope

This applies to all project spaces: issues, pull requests, discussions, and any other official communication channel for the project.

## Enforcement

Maintainers may remove, edit, or reject contributions that violate this code of conduct, and may temporarily or permanently ban contributors for repeated or severe violations. Report concerns by opening an issue marked confidential, or by the contact method listed in the repository's profile, if one is configured.
